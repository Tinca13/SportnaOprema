## 🚀 Features

* **User Authentication**: Secure login system with role-based access (User/Admin).
* **Inventory Management**: Real-time display of available equipment and categories.
* **Rental Workflow**:
    * **User**: Browse items, add to cart, and submit rental requests.
    * **Admin**: View all rental requests, approve them (reduces stock), and process returns (restores stock).
* **Dynamic UI**: Automatic updates of stock levels and rental statuses.

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
* **Backend**: Node.js with Express.js
* **Database**: MariaDB (v10.x or higher)

## 📋 Prerequisites

* Node.js (v14 or higher)
* MariaDB Server
* HeidiSQL (recommended for MariaDB management)
